Это пустой flutter проект.
Спланируй написание приложения (только андроид) для челленджей. Смысл такой: можно задать произвольное кол-во каких-то эвентов на какой-то произвольный отрезок времени и пользователь будет отмечать выполнение этих эвентов. (например челлендж такой: 100 фильмов за год, пользователь сам задаёт эти параметры, и в течение этого года пользователь отмечает выполнение этих эвентов, в данном случае просмотр фильмов). У пользователя есть возможность назвать челлендж своим именем. 
Язык для всего текста в приложении используй русский.

Структура приложения:
1 Главный экран. В аппбаре название приложения "CHALLENGER". По центру отображаем текущую статистику челленджа (кол-во выполненных из кол-ва всего (арка нарисованная кастом пэинтером), кол-во оставшихся дней, темп, проектное кол-во, оптимальная периодичность выполнения челленджа (например 1 фильм раз в 3 дня, причём это число должно пересчитываться автоматически, если, например, пользователь за 1 день посмотрел 3 фильма вместо оптимального 1 за 3 дня)). Ниже список выполненных пунктов. FAB (иконка + текст) - добавить новый пункт, по нажатию открывается bottom sheet с возможностью добавить опциональную информацию (название, дата, плюс пункты из настроек), в самом низу в том же месте, где и FAB кнопка сохранить. 

2 экран с настройками, тут 
- cвитч для переключения вибрации
- тема + главный цвет приложения
- виджеты: кнопка добавить, по которой открывается системное меню добавления виджета (виджеты можно такие 1х1 (отображаем просто арку как на главной с 1/10 например), 1х2 (арка как на 1х1 + кол-во оставшихся дней), 1х4 (как 1х2 + доп статистика + кнопка добавить), 2х2 (как 1х2 только поболше), 2х4 (как 1х4 только побольше))
- настройка текущего челленджа (возможность добавлять кастомные пункты для эвентов, по-умолчанию только название (текст) и дата (дата, по-умолчанию сегодня). Эти пункты будут показываться при добавлении эвента по нажатию на FAB на главной. Есть возможность добавить пункты с такими типами: текст, число, дата)
- уведомления (есть возможность включить уведомления с оптимальной периодичностью выполнения челленджа, и уведомления должны как раз приходить с оптимальной периодичностью), есть возможность выбрать предпочитаемое время для уведомления (утро, день, вечер)
